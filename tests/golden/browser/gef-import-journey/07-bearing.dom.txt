Bearing capacity is shown as a shallow-foundation screening curve using the interpreted layer active at each founding depth. Layered failure mechanisms and full eccentric-load verification are not modeled here.
The current bearing check uses EC7 Annex D rough base for Nγ and Brinch Hansen / Annex D for shape factors. In Brinch Hansen / Annex D mode the shape factors follow the effective-dimension ratio r = B′/L′. It includes Df/B′ depth factors, but it still assumes level ground, horizontal base, and no horizontal load.
Belgian bearing checks should normally review both DA1/1 and DA1/2; the governing result is the recommended default in this tool.
gamma_Rd is kept as an optional model factor only. Leave it at 1.0 unless you intentionally want an extra correction for simplified analytical model bias.
