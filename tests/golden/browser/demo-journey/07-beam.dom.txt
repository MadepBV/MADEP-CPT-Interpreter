Full-length uniform loading is mainly a settlement case in this 1D model; longitudinal bending can be near zero because soil reaction balances the load almost uniformly.
k_s is not a fixed soil material constant. It depends on the interpreted CPT stiffness, the loaded width B, the averaging depth, and the strip stiffness. As a rough order of magnitude only: very soft support may be around 5,000-20,000 kN/m³, medium support 20,000-80,000 kN/m³, and stiff/dense support 80,000-200,000+ kN/m³. Use these only as a sanity check, not as target values.

Stage 6 Pasternak uses a 1D beam/strip model. True 2D slab-on-grade plate behaviour still needs FE or a dedicated analytical plate solution.
Model interpretation is 1 m slab strip: x is the checked slab direction, b is normally 1.00 m, and outputs are per meter only when b = 1.00 m.
beta*L is below pi, so finite-beam behaviour matters. A numerical beam-on-Winkler solve is therefore used instead of relying on the infinite-beam shortcut.
Default ks derivation uses Es = E_oed and ν = 0 for consistency with the oedometric stiffness route. Switch to drained Young modulus mode if a project-specific conversion is preferred.
Pasternak shear coupling is inferred from the CPT stiffness profile as G_p ≈ eta·G_s,avg·H_p. This is a screening approximation, not a calibrated Belgian design value.
Current Pasternak inputs: G_p = 101171 kN/m, G_s,avg = 33724 kPa, H_p = 3.00 m, eta = 1.00.
Uniform full-length load on a free Winkler beam can legitimately give nearly constant settlement w ≈ q/k and almost zero bending moment. If you want edge-driven or local bending, use a patch / point load case or a 2D plate model.
